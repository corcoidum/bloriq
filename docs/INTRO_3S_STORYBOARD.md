# 3초 인트로 제안 — 작은 발자국, 깨어나는 별

**콘티 제안이며 런타임 구현은 하지 않았다.** 현재 신규 사용자의 실제1번 튜토리얼, 재방문자의 홈 진입, 설정의 기존4초 다시 보기는 그대로다. 영상 파일·추가 오디오·새 재생 상태 키를 추가하지 않았다.

## 장면과 타이밍

| 시간 | 장면 | 전달할 의미 |
|---|---|---|
| 0.0~0.4초 | 밤숲의 작은 달빛 석판과 리크 눈 옆 별 표식이 밝아진다 | 브랜드·주인공 인지 |
| 0.4~1.1초 | 리크가 한 칸 이동하고 떠난 칸에 Purple Echo가 남는다 | 이동이 잔상을 만든다 |
| 1.1~1.9초 | 다음 이동이 끝나며 이전 Echo가 새 자리로 교체되고 Gold 별문에 도착한다 | 한 턴 잔상과 목표 |
| 1.9~2.4초 | 별문 너머 모리가 눈을 뜨고 작은 상하 반응을 한다 | 퍼즐 너머 기다리는 친구 |
| 2.4~3.0초 | BLORIQ — THE LAST ECHO와 “Every Move Leaves an Echo.” | 짧은 브랜드 마무리 |

보호자의 정체·관측소 기록·후반 정령은 보여 주지 않는다. 빠른 화면 흔들기·전체 섬광·큰 폭의 줌을 쓰지 않고 별문 주변의 짧은 빛과 소량의 입자로 흥분감을 만든다. 긴 설명문과 새 버튼을 추가하지 않는다.

## 향후 구현 권장안

- Flutter 타임라인과 실제 보드·리크·Echo·별문·모리 아트를 재사용한다. 별도 인코딩 영상은 필요 없다.
- 최초1회3초, 이후에는 홈으로 바로 진입한다. 최초 사용자는 끝나면 실제1번 튜토리얼로 연결한다. 설정에서 다시 볼 수 있다.
- 처음부터48px 이상 건너뛰기 버튼을 제공한다. 완료·건너뛰기 연속 입력에도 전환은 한 번만 한다.
- 기본 무음, 자동 BGM 시작 없음. 플레이 뒤의 기존 오디오 설정을 따른다.
- 앱·시스템의 모션 줄이기에서는 생략한다. 백그라운드로 가면 종료하고 복귀 시 반복하지 않는다.
- 데이터 로딩과 종료 타이밍을 분리한다. 로딩 실패는 원래 홈의 재시도 흐름으로 처리한다.
- 독립 종료 타이머와 dispose 정리를 두며, 데모로 진행·별·수집·Daily 기록을 변경하지 않는다.

위 재생 정책과3초 타임라인은 후속 구현 제안이다. 이번 변경을 새 인트로가 자동 재생되는 버전으로 보고하지 않는다.
