# BLORIA 시즌 1 캐릭터 바이블

리크: 크림색 둥근 몸, 눈 옆 별 표식, 짧은 보라 Echo 꼬리. 호기심 많고 다정한 기억을 잃은 전령. 정령은 퍼즐 능력치를 바꾸지 않는다.

모든 정령은 짧은 팔다리와 단순한 눈을 공유하며, 귀·장식·꼬리·날개로 구별한다. 앱의 Canvas 아트는 외부 이미지 없이 오프라인으로 렌더링된다.
