# 기믹 조합 규칙

## 세계 7-A 조합표

아래 표는 9개 기믹과 4개 권능의 서로 다른 78쌍을 한 번씩 다룬다. 대각선에는 같은 규칙을 한 판에 배치할 때의 한도를 적었다. 6×6에서 탐색 한도에 걸린 조합은 [비용 측정과 생성 제한](MECHANIC_COST.md#세계-7-a-혼합-판)에서 따로 다룬다.

- **한 수의 순서**는 이동 전 잔상·시각으로 진입과 출발을 검사하고, 첫 착지 → 주 블록의 얼음 → 책장 문 → 거울 짝의 이동·얼음·책장 문 → 잔상·시각 갱신 순이다. 성공한 한 수에만 시각이 한 번 오른다.
- **분리**는 서로 다른 칸에 배치한다는 뜻이다. 칸 기믹은 바위와도 겹칠 수 없다. 책장 끝점만 바위, 민들레, 호박석, 클로버와 겹칠 수 있다. 달 수정과 문은 별문과 겹칠 수 없으며 블록을 닫힌 문 위에 놓고 시작할 수 없다.
- **잔상**은 주 블록의 첫 출발 칸으로 정한다. 민들레는 지우고 호박석은 이전 잔상을 유지한다. 봉인과 빛 교대의 판정이 이보다 우선한다. 얼음·책장·짝의 이동으로 잔상이 더 생기지 않는다.
- **별문**에 리크가 도착하면 클리어다. 룬석은 거울 짝으로 끌려가는 첫 한 칸에만 별문에 들어갈 수 있다. 그때도 클로버 등 다른 진입 조건은 적용하며 룬석만 도착해서는 클리어되지 않는다.

## 얼음과 다른 규칙이 만날 때

얼음은 `{"type":"ice","positions":[{"x":1,"y":2}]}`로 정의한다. 블록이 얼음에 착지하면 같은 방향으로 계속 전진하고, 얼음이 아닌 첫 칸에 들어가거나 다음 칸에 들어갈 수 없을 때 멈춘다. 얼음 칸에도 블록의 시작 위치나 별문을 둘 수 있다.

| 조합 | 판정 |
| --- | --- |
| 바위·블록·판 경계 | 다음 칸에 들어갈 수 없으면 현재 얼음 칸에 멈춘다. |
| 이전 잔상·이번 수의 출발 칸 | 이전 잔상과 주 이동에서 방금 비운 칸은 이동이 끝날 때까지 통과할 수 없다. |
| 민들레·호박석 | 주 이동의 출발 칸이 민들레이면 잔상을 지우고, 호박석이면 이전 잔상을 유지한다. 일반 출발 칸에는 그 칸에만 잔상을 남긴다. 멈춘 칸의 출발 규칙은 다음에 떠날 때 적용한다. |
| 클로버 | 리크만 들어갈 수 있다. 룬석은 클로버 바로 앞에서 멈춘다. |
| 물길·시곗바늘 | 첫 출발은 이동 전 방향을 검사한다. 얼음에서 이어지는 동안에는 진입 가능 여부만 본다. 화살표 칸에 멈췄다면 다음 수에 그 칸의 방향을 검사한다. 얼음과 화살표가 겹친 데이터는 거부한다. |
| 별문 | 리크는 별문에 닿자마자 멈추고 클리어한다. 얼음 위의 별문에도 같다. 일반 이동과 얼음으로 연장되는 구간에서는 룬석이 별문에 들어갈 수 없다. |
| 거울 짝 | 일반 이동에서 먼저 밀린 블록의 정지 칸을 확정한다. 그 위치를 장애물로 두고 짝이 반대 방향으로 한 칸 이동한 뒤, 착지가 얼음이면 이어서 미끄러진다. 짝의 첫 칸은 기존 거울 짝 규칙으로 판정한다. 짝은 잔상을 남기지 않으며, 리크가 짝으로 별문에 닿아도 클리어한다. |
| 시각 | 주 이동과 짝의 이동을 합쳐 1수다. 시곗바늘이 있는 판의 시각은 한 번만 오른다. |
| 달 수정 문 | 이동 전 잔상으로 문에 들어갈 수 있는지 검사한다. 두 블록의 정지가 끝나면 새 잔상으로 문 상태를 갱신한다. |
| 바람 | 기존 바람 판정으로 정지 칸까지 이동한다. 그 칸이 얼음이어도 얼음 이동을 다시 적용하지 않는다. |
| 달꽃 도약 | 바위를 뛰어넘은 착지 칸이 얼음이면 도약 방향으로 이어서 미끄러진다. |
| 빛 교대 | 이전 잔상 칸이 얼음이어도 그 자리에 놓인다. 교대의 출발 칸에 새 잔상을 남긴다. |
| 봉인 | 한 칸 이동한 착지가 얼음이면 미끄러진다. 봉인으로 유지한 이전 잔상이 끝까지 장애물이 된다. |

Dart와 Python은 첫 착지 판정 → 주 이동의 얼음 변환 → 책장 문 변환 → 거울 짝 변환 → 잔상·문·시각 갱신 순으로 처리한다. 권능으로 이동할 때 거울 짝은 따라오지 않는다. 풀이 데이터는 변환 전 첫 착지를 기록하며, 되돌리기와 리플레이에는 정지 위치가 포함된 이동 전후 상태를 쓴다.

임시 보드는 무작위 표본 2263번에서 권능을 끈 구성이다. 360×740 캡처는 리크를 오른쪽으로 드래그했을 때의 정지 칸을 보여 준다. [얼음 규칙 캡처](screenshots/world5/ice-rule.png)

## 책장 문과 다른 규칙이 만날 때

`{"type":"shelfDoor","pairs":[{"a":{"x":1,"y":2},"b":{"x":4,"y":0}}]}`로 한 판에 한두 쌍을 배치한다. 각 끝점은 판 안의 서로 다른 칸이어야 한다. 얼음·물길·시곗바늘·별문·달 수정·문과 겹치면 데이터 검증에서 거부한다. 책장 위 바위와 클로버는 진입을 막을 수 있다.

| 함께 쓰는 규칙 | 동작 |
| --- | --- |
| 일반 이동 | A에 착지하고 B에 들어갈 수 있으면 B로 건너간다. B가 막혔으면 A에 멈춘다. B에서 평범한 칸으로 나가는 수는 그대로 이동한다. 이후 B에 다시 들어오면 A를 검사한다. |
| 장애물·클로버·달 수정 문 | B는 일반 이동의 진입 판정을 공유한다. 바위, 블록, 이전 잔상, 이번 수의 출발 칸, 룬석의 클로버 진입, 닫힌 문이 장애물이다. 문이 B에 오는 배치는 데이터 검증에서 거부한다. |
| 얼음 | 얼음에서 처음 닿은 책장 A에서 미끄러짐이 끝난다. 이어서 B를 검사한다. B에서 같은 방향으로 다시 미끄러지지 않는다. |
| 잔상 | 기본 잔상은 주 이동의 출발 칸에만 생긴다. 순간 이동의 입구·출구에는 추가 잔상이 생기지 않는다. 다음 수에 책장에서 출발하면 그 책장에 평소 출발 칸 규칙이 적용된다. 민들레·호박석과 봉인의 잔상 처리도 유지한다. |
| 거울 짝 | 주 이동과 순간 이동을 먼저 확정하고, 그 배치를 장애물로 삼아 짝의 반대 방향 이동·얼음·책장 문을 차례로 계산한다. 주 블록이 B를 차지한 뒤 짝이 A에 들어오면 짝은 A에 멈춘다. 두 블록은 각각 최대 한 번 건너가며 짝은 잔상을 남기지 않는다. |
| 별문 | 책장 끝점과 별문은 서로 다른 칸이다. 출구에 직접 들어가는 기존 클리어 규칙을 쓴다. |
| 달꽃 도약 | 도약의 착지부터 얼음을 적용한 후 마지막 칸에서 책장 문을 검사한다. |
| 바람 | 기존 바람의 정지 칸에서만 책장 문을 검사한다. 바람으로 지나는 책장에서는 계속 이동한다. |
| 빛 교대 | 잔상 자리인 책장 칸에 놓이며 그대로 정지한다. |
| 시곗바늘 | 순간 이동이나 짝 이동이 섞여도 성공한 한 수는 시각을 1만 올린다. |

한 블록의 순간 이동은 착지당 한 번이다. 두 solver는 최종 배치를 쓰며, 순간 이동 기록은 화면과 리플레이에만 사용한다. 360×740 임시 보드는 무작위 표본 3006번의 첫 수를 드래그하는 장면이다. 점선 궤적은 얼음 구간을 따라 A에서 끝나고, 반투명 리크는 B의 도착 위치를 나타낸다. [책장 문 규칙 캡처](screenshots/world6/shelf-rule.png)
