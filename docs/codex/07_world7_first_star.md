# 세계 7 첫 별 — 종장 「마지막 잔상」

새 규칙은 없다. 지금까지의 규칙과 권능을 한 하늘에서 섞고, 사가의 엔딩을 만든다. 네 작업으로 나눈다.
위험은 두 가지다. 기믹을 섞으면 **탐색 비용이 커지고**, **엔딩 연출을 새로 만들어야** 한다.

---

## 7-A 혼합 판 생성 준비

```text
BLORIQ 저장소에서 "세계 7-A: 혼합 판 생성 준비"를 진행해 줘. AGENTS.md를 따르고, origin/main에서 codex/w7-mix-prep 브랜치를 만든다. 세계 6이 main에 공개되어 있어야 한다.

1. 혼합 규칙 점검
   - docs/MECHANIC_RULES.md의 규칙 조합표를 모든 쌍(세계 1 칸 5종 + mirrorPair, clockArrow, ice, shelfDoor + 권능 4종)으로 채운다. 아직 정하지 않은 조합(예: 시곗바늘 칸 위 책장? → 겹침 금지 / 짝 상대가 바람에 밀릴 때 등)이 있으면 가장 단순한 규칙을 정해 두 solver에 넣고 테스트한다.
   - 두 solver 일치 테스트에 "기믹 2~3개 + 권능 0~1개 무작위 혼합 판" 500개를 추가한다.

2. 비용 상한
   - 5×5, 6×5, 6×6에서 기믹 2개 + 권능 1개 혼합 판의 탐색 비용을 docs/MECHANIC_COST.md에 추가한다.
   - 6×6에서 앱 힌트(isolate, 1.5초)가 안 끝나는 조합은 생성기에서 금지 조합으로 둔다. 캠페인 판은 solution이 저장되므로 판 처음 상태 힌트는 문제없다는 점도 확인한다.

3. 생성기 확장
   - tools/design_world.py에 슬롯별 "기믹 후보 목록에서 정확히 k개 고르기"와 "각 기믹이 모두 필수(장식 금지)" 조건을 넣는다.
   - 6×6 판을 위한 탐색 예산·시간 설정을 넣는다.

검증 명령 통과 후 커밋·푸시·보고. saga는 그대로.
```

## 7-C 이야기와 공개

```text
BLORIQ 저장소에서 "세계 7-C: 첫 별 이야기와 공개"를 진행해 줘. AGENTS.md를 따르고, 7-B 브랜치에서 codex/w7-story를 만든다. 절차는 docs/codex/03_world3_mirror_lake.md의 3-C를 세계 7에 맞게 따르되, 안내 카드는 새 규칙 대신 "지금까지 배운 규칙이 모두 나와요" 한 장으로 한다.

세계 7 값:
- worldId "w7", globalChapter 31~35, 정령 s7-01~25, 레벨 601~625.
- 등대가 아닌 세계(lighthouse 없음). theme: 깊은 밤하늘 판, 별빛 테두리, 다섯 등대 색이 섞인 강조. bgm_w7.wav(세계 1 곡의 선율을 느리게 변주한 루프).
- 정령 25명: 1~4장은 지금까지 만난 가문의 "다음 세대"나 사촌으로, 다섯 세계의 가문이 한 번씩 다시 등장하게 한다. 5장 수호 정령은 아스테르(세계 1)와 각 등대 수호 정령이 함께 지키는 판으로 쓴다(새 정령 id는 그대로 s7-NN).
- 이야기:
  · 프롤로그: 다섯 등대가 모두 켜지고 빛길이 하나로 이어진다. 그 끝에서 첫 별이 눈을 뜨려 한다.
  · 1 빛길의 시작 — 달빛 숲 친구들이 배웅한다. 아스테르가 처음으로 리크에게 사과한다.
  · 2 거울과 시계 — 호수의 그림자와 멈췄던 시계가 리크의 기억을 함께 맞춘다.
  · 3 얼음과 책장 — 녹은 기억과 '첫 잔상' 책이 한 장면을 보여 준다: 첫 별이 사라지기 전, 마지막 빛을 작은 잔상으로 남겼다.
  · 4 다섯 등대의 합창 — 등대 수호 정령들이 빛을 모은다.
  · 5 마지막 잔상 — 리크는 첫 별이 남긴 마지막 잔상이었다. 리크가 돌아오자 첫 별이 다시 켜진다.
- 반전은 5장 결말에서만 말한다. 앞 장은 암시만 한다.

공개: saga.json 세계 7 playable, pubspec, 업적·칭호("첫 별의 잔상")와 전용 이동 잔영 "첫 별빛" 추가(progression_rules, 저장 형식 변경 없음). 세계 6을 마치면 세계 7이 열리는지, 빛길 지도의 일곱째 칸이 진행 중으로 보이는지 확인.

검증 명령 통과, 캡처 6장(docs/screenshots/world7/), README·SAGA 갱신. 버전은 아직 올리지 않는다(7-D에서 1.0 후보로). 커밋·푸시·보고.
```

## 7-D 엔딩, 크레디트, 1.0 후보

```text
BLORIQ 저장소에서 "세계 7-D: 엔딩과 1.0 후보"를 진행해 줘. AGENTS.md를 따르고, 7-C 브랜치에서 codex/w7-ending을 만든다.

1. 엔딩 연출 (lib/world/ending_screen.dart 새로)
   - 세계 7의 마지막 별자리를 완성하면 결과 팝업의 "다음 세계로" 대신 "빛길의 끝으로" 버튼을 보여 주고, 누르면 엔딩을 재생한다.
   - 순서(약 40초, 화면을 누르면 다음 장면, 건너뛰기 버튼 상시):
     a) 빛길 지도가 화면을 채우고, 등대 다섯 개가 세계 순서대로 하나씩 켜진다(각 등대 색).
     b) 빛길이 첫 별까지 이어지고, 리크가 그 길을 걸어 올라간다(지나간 칸에 잔상이 한 칸씩 남았다 사라진다 — 게임 규칙을 연출로).
     c) 리크가 첫 별에 닿으면 화면이 하얗게 밝아지고, 첫 별이 켜진다.
     d) 다섯 세계 수호 정령과 아스테르가 하늘에 별자리로 떠오른다(이미 있는 ConstellationPainter·초상 재사용, 그림이 없으면 별 모양).
     e) 마지막 문장(ko/en): "리크는 첫 별이 남긴 마지막 잔상이었어. 그리고 이제, 첫 별이야."
   - 모션 줄이기: 장면 전환을 페이드로만, 입자 없음.
   - BGM: 엔딩용 짧은 곡 ending.wav(tools/generate_audio.py로 합성).

2. 크레디트 화면: 사가 이름, 일곱 세계 이름, 만든 이(corcoidum), 사용 글꼴·오픈 라이선스(OFL 목록), "플레이해 줘서 고마워요". 설정 메뉴에서 다시 볼 수 있게 한다.

3. 엔딩 뒤 안내 카드: "별바다 항해"와 "잔상의 시련"(만들어져 있으면) 입구, 그리고 사가 완료 보상(칭호·이동 잔영) 표시. 홈의 빛길 지도는 모든 등대가 켜진 모습으로 바뀐다.

4. 기록: 엔딩을 봤는지는 기존 성장 저장소의 확장 필드로 저장한다(없던 필드를 더하는 것만 허용, 옛 데이터를 읽을 수 있어야 함). 엔딩을 이미 본 사람은 다시 볼 때 건너뛰기가 바로 활성화된다.

5. 1.0 후보 정리
   - pubspec 버전 1.0.0+N. README를 "일곱 세계 175판 + 항해 + 오늘의 잔상" 기준으로 다시 쓴다.
   - 모든 세계를 테스트용 저장 데이터로 연속 공개 → 세계 7 완료 → 엔딩까지 가는 통합 테스트 하나.
   - 320×568 글자 200%, 360×740, 393×852에서 엔딩·크레디트 넘침 없음.
   - flutter analyze, flutter test -r failures-only, validate_levels, level_audit(세계 3~7), flutter build apk --release.
   - 캡처: 엔딩 장면 a~e 5장, 크레디트 1장(docs/screenshots/ending/).

커밋·푸시·보고. main 병합과 출시 서명은 사람이 확인한 뒤 한다.
```
