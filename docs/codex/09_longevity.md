# 09 오래 즐길 거리 — 세계 3 출시 뒤 아무 때나

세계 하나를 만드는 데는 하루가 걸리고, 깨는 데는 반나절이 걸린다. 세계 사이를 이 콘텐츠로 채운다. 각 작업은 따로 실행할 수 있다.

---

## 09-A 판마다 도전 과제 3개

```text
BLORIQ 저장소에서 "도전 과제 3개"를 진행해 줘. AGENTS.md를 따르고, origin/main에서 codex/stage-challenges 브랜치를 만든다.

- 확장 세계(세계 2 이상)의 모든 판에 도전 과제 3개를 붙인다: ① 깨기 ② 최단 수 이하로 깨기 ③ 권능·도움 없이 깨기(맨손으로 풀 수 없는 판은 "권능 한 번만 쓰고 깨기").
- 지금의 별 3개와 겹치지 않게, 도전 과제는 별과 따로 "별꽃"(작은 꽃 표식)으로 센다. 판 카드, 세계 지도, 결과 팝업에 별꽃 3칸을 보여 준다.
- 기록은 ProgressRepository에 새 필드를 "더하는" 방식으로 저장한다(옛 데이터 읽기 유지, 이전 테스트 포함). 이미 깬 판은 기존 기록으로 소급해 ①②③을 채울 수 있는 만큼 채운다.
- 보상: 세계마다 별꽃 25/50/75개 업적(별가루, 이동 잔영, 칭호). progression_rules의 업적 목록에 추가.
- 결과 팝업에서 이번에 새로 딴 별꽃이 피어나는 짧은 연출(모션 줄이기에서는 즉시).
- 테스트: 각 과제 판정, 소급, 업적 지급, 작은 화면 넘침.
검증 명령 통과 후 커밋·푸시·보고. 캡처 docs/screenshots/challenges/ 3장.
```

## 09-B 잔상의 시련

```text
BLORIQ 저장소에서 "잔상의 시련"을 진행해 줘. AGENTS.md를 따르고, origin/main에서 codex/echo-trials 브랜치를 만든다.

- 마친 세계마다 "시련" 10판을 연다. 원본 판을 lib/endless/endless_pool.dart의 transformLevel로 회전·반전하고, 조건 하나를 더한다: 이동 수 제한(최단 수+2), 되돌리기 금지, 권능 금지(맨손으로 풀리는 판만) 중 하나.
- 판 선택은 세계와 날짜가 아니라 고정 씨앗으로 정한다(모두 같은 시련). 시련 목록은 앱이 시작할 때 계산하지 말고 tools/로 미리 만들어 assets/levels/trials_v1.json에 저장한다(변환 번호, 원본 id, 조건, 최단 수).
- 진입: 세계 지도 아래 "시련" 버튼(세계를 마친 뒤에만 보임).
- 황금 별자리 보상: 장의 별자리를 황금으로 만들면 그 장의 판에서 나온 시련 2판이 세계를 마치기 전이라도 먼저 열린다(세계 지도 장 화면에 "황금 시련" 입구). 황금 별자리의 실력 보상을 새 퍼즐로 주기 위해서다.
- 보상: 시련 10판을 모두 깨면 그 세계의 시련 칭호와 이동 잔영 색 변형.
- 기록은 새 저장소 키(bloriq.trials.v1)로 따로 둔다.
- 테스트: 변환 뒤 최단 수 유지, 조건 판정, 보상 한 번만 지급, 저장·복원.
검증 명령 통과 후 커밋·푸시·보고. 캡처 3장.
```

## 09-C 별바다 항해 v2 — 세계 기믹이 섞인 바다

```text
BLORIQ 저장소에서 "별바다 항해 v2"를 진행해 줘. AGENTS.md를 따르고, origin/main에서 codex/endless-v2 브랜치를 만든다. 설계 문서는 docs/ENDLESS.md.

- tools/design_endless.py에 "세계 기믹 단계"를 추가한다: 세계 N의 새 기믹이 들어간 판 묶음(세계당 120판, 최단 6~14수). 장식 기믹 금지 검사는 그대로. 기존 판 id와 저장된 항해가 깨지지 않게 새 판은 기존 최대 id 뒤에 붙이고, 파일은 endless_pool_v1.json에 이어 쓰거나 v2로 분리한다(docs/ENDLESS.md "묶음을 바꿀 때" 규칙).
- 항해 중 판을 고를 때, 플레이어가 마친 세계의 기믹 판만 섞는다. 깊이 6 이후 3판에 1판꼴. 아직 안 마친 세계의 기믹은 절대 나오지 않는다.
- 바다 이름 표시: 그 판의 기믹에 따라 "거울 바다", "시계 바다", "얼음 바다", "서고 바다".
- 기존 규칙(등불, 점수, 콤보, 이정표)은 바꾸지 않는다. 이정표 150·200판을 추가할지 제안만 보고에 적는다.
- 테스트: 마친 세계에 따라 섞이는 판이 달라짐, 결정적 선택(같은 씨앗 → 같은 판), 기존 저장 항해 복원, 판 재검증 일부.
검증 명령(+ python3 -m tools.design_endless --check) 통과 후 커밋·푸시·보고.
```

## 09-D 주간 별자리

```text
BLORIQ 저장소에서 "주간 별자리"를 진행해 줘. AGENTS.md를 따르고, origin/main에서 codex/weekly-constellation 브랜치를 만든다.

- 매주 월요일(기기 날짜)에 고정 5판이 열린다. 판은 오늘의 잔상 묶음과 항해 묶음에서 주차 키로 결정적으로 고른다(lib/daily/ 재사용). 마친 세계의 기믹만 쓴다.
- 5판을 모두 깨면 그 주의 별자리가 완성되고 한정 이동 잔영 색 또는 칭호를 받는다(12주 순환 목록).
- 홈의 오늘의 잔상 카드 옆에 작은 주간 카드. 기록은 새 키 bloriq.weekly.v1.
- 테스트: 주차 계산(연말 경계), 결정적 선택, 보상 한 번만, 시계를 되돌려도 지난 주 판이 바뀌지 않음.
검증 명령 통과 후 커밋·푸시·보고.
```
