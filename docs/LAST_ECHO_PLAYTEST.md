# 첫 챕터 — 5명 무설명 관찰표

아직 사람 관찰을 수행하지 않았다. 자동 테스트와 화면 캡처는 아래 결과를 대신하지 않는다. 이름 대신 임의 참여자 번호 P01~P05를 사용한다. 수집 동의 시간은 규칙 학습 시간에서 분리한다.

## 진행

1. 신규 데이터로 시작하고 기기·빌드 SHA·언어·글자 크기·모션 설정을 기록한다. 광고는 없다.
2. 설명 없이 기기를 건넨다. 먼저 화면에서 스스로 조작하는지 본다. 막혔다고 즉시 해법을 알려 주지 않는다.
3. 최대 첫 5개 퍼즐을 진행한다. 다음 별문을 선택한 이유와 모리/루나벨 기억을 이해한 정도를 짧게 묻는다.
4. 홈·도감에서 기억을 다시 읽고 동행을 바꾸게 한다. 내보내기는 동의한 경우 사용자가 명시적으로 선택한다.

## 판정과 다음 수정

- 첫 점검은 **4/5명이 도움 없이 Echo를 설명하고 튜토리얼을 완료하는가**다. 작은 표본의 탐색적 기준이며 전체 완료율이나 리텐션 실적으로 발표하지 않는다.
- 규칙 이해와 블록 구분 문제가 있으면 서사·연출을 더 늘리기 전에 고친다.
- 일반 기억은 읽지 않고 바로 다음을 누를 수 있어야 한다. 발견을 넘겨도 나중에 도감에서 읽는지 확인한다.
- 5번 작은 결말에서 보호자의 정체를 확정해 말하게 유도하지 않는다. 첫 챕터는 질문만 남긴다.
- 실기기에서는 무음·BGM/효과음·백그라운드/복귀·오프라인·앱 종료 중 보상 복구도 별도로 확인한다.
- Android profile 프레임 수치·Crash-free users·D1/D7은 실측 자료가 있을 때만 기록한다. 이번 작업에서는 미측정이다.
