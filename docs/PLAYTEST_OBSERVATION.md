# 5명 무설명 플레이 관찰표

상태: 템플릿. 실제 참가자 관찰 결과는 아직 없다. 참가자 이름·연락처를 적지 않고 테스트 코드 A~E로 기록한다. 모집·동의·원본 내보내기 관리는 테스트 진행자가 수행한다.

## 진행 방법

1. 참가자의 기존 진행 기록이 없는 테스트 설치를 준비한다. 앱 데이터 삭제는 참가자 소유의 실제 진행 기록을 지우므로 별도 테스트 기기/프로필을 사용한다.
2. 분석 동의는 선택 사항이다. 테스트 빌드의 동의 화면에 쓴 시간과 퍼즐의 첫 인터랙션까지 시간을 분리한다. 거절해도 동일한 게임을 제공한다.
3. “자유롭게 플레이해 주세요” 외에 Echo 규칙이나 정답을 설명하지 않는다. 손을 대신 움직이거나 첫 드래그를 보여주지 않는다.
4. 자발적인 도움말·건너뛰기·Undo·Restart를 관찰한다. 막혀서 개입했다면 시점·내용을 적고 ‘무도움 성공’으로 집계하지 않는다.
5. 튜토리얼과 첫 5레벨 후 “방금 떠난 칸으로 왜 돌아갈 수 없었나요?”를 물어 이해 여부를 기록한다. 성공한 이동만으로 이해했다고 단정하지 않는다.

## 첫 판단과 후속 확인

- 첫 점검은 4/5명이 별도 설명 없이 튜토리얼을 끝내고 Echo 차단을 설명하는지 본다. 적은 표본의 탐색적 기준이며 통계적 효과 검증이 아니다.
- 5레벨은 보드가 4×4로 넓어진다. 자동 감사의 탐색량 경고를 실제 난이도와 함께 확인한다. 8레벨은 두 신규 기믹이 동시에 등장하는 구간이므로 추가 관찰한다.
- 1레벨 5~15초, 2~5레벨 15~60초, 이후 30~90초는 가설이다. 목표를 맞추려고 기다리게 하거나 설명을 늘리지 않는다.
- 문제 발견 시 규칙 이해→첫 5레벨→조작→재도전→Daily 순으로 고친다. 광고 추가나 콘텐츠 수 증가는 해결책으로 간주하지 않는다.
- 20~50명 후속 테스트에서는 첫 관측 날짜·추적 기간·내보내기 회수 여부·수집 중단·잘린 로그를 함께 관리한다. 기록을 받지 못한 사람의 D1/D7을 임의로 0으로 채우지 않는다.
- KPI는 사용자 제시 제품 목표다: 튜토리얼 80%/확장 85%, 5레벨 도달 50%/65%, D1 30%/35%, D7 8%/12~14%, 평균 세션 4분/4~7분, Crash-free 99.5%/99.8%. 이 문서와 합성 테스트는 성과 자료가 아니다.
