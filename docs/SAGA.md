# BLORIQ 사가 — 다섯 등대의 빛길

2026-11-11 · 모든 세계를 꿰는 큰 줄거리와, 새 세계를 데이터로 붙이는 방법을 정리한 작가·개발용 문서다. 결말을 포함한다.
화면이 읽는 원본은 [`assets/worlds/saga.json`](../assets/worlds/saga.json)이다. 이 문서와 다르면 JSON이 맞다.

## 한 줄 줄거리

> 다섯 등대는 한 줄의 빛으로 이어져 첫 별까지 길을 비추고 있었다. 어느 밤 등대가 하나씩 멈추고 빛길이 끊겼다. 잔상을 남기며 걷는 리크가 등대를 하나씩 다시 켜면, 마지막에 첫 별이 기다린다.

세계 1에 이미 씨앗이 있다. 포미의 기억 "다섯 등대는 한 줄의 빛으로 이어져 있었어", 2장 결말 "다섯 등대는 하나의 길을 비추고 있었어", 5장 결말의 아스테르 고백과 리크의 별 표식. 사가는 이 씨앗을 일곱 세계로 키운다.

## 수수께끼 네 가닥

세계마다 하나씩 풀고, 세계 끝에서 다음 질문을 하나 던진다. "다음엔 뭐지?"가 다시 접속할 이유다.

| 가닥 | 처음 던지는 곳 | 풀리는 곳 |
|---|---|---|
| 리크는 누구인가 | 세계 1 · 옛 등대 기록의 별 표식 | 세계 2(등대의 첫 불씨) → 세계 7(첫 별의 마지막 잔상) |
| 잔상은 무엇인가 | 세계 2 끝 · 호수 위를 혼자 걷는 잔상 | 세계 3(잃어버린 기억이 남긴 그림자) |
| 등대는 왜 멈췄나 | 세계 1 · 아스테르의 고백 | 세계 4(멈춘 밤), 세계 5(기억 보존 장치) |
| 첫 잔상은 누가 만들었나 | 시즌 1에서 남겨 둔 질문 | 세계 6(첫 별 자신) → 세계 7 |

- 세계 7의 부제 "마지막 잔상"은 게임의 옛 제목(The Last Echo)과 이어진다.
- 새 규칙은 세계마다 하나만 더한다. 이미 배운 규칙과 권능은 다음 세계에서도 섞어 쓴다.
- 세계 3~6의 규칙은 세계를 공개할 때 Dart와 Python 기믹 레지스트리에 함께 등록한다.

## 세계 하나의 모양

모든 세계가 같은 틀을 쓴다. 그래야 데이터만 채워 넣으면 새 세계가 열린다.

- **5장 × 5스테이지 = 25판.** 각 장의 다섯째 판은 수호 정령 판이다.
- **장마다 별자리 1개.** 다섯 판을 깨면 별자리가 완성되고, 다섯 별자리를 모두 완성하면 다음 세계가 열린다.
- **정령 25명.** 판마다 한 명, 장마다 가문 하나.
- **이야기 흐름:** 세계 프롤로그 → 장 소개(intro) → 장 결말(endingTitle, ending) → 세계를 마치면 `reveal`이 풀리고 다음 세계 `teaser`가 보인다.
- **난이도 톱니:** 장의 첫 판이 가장 쉽고 다섯째 판이 정점이다. 세계 평균은 앞 세계보다 조금 깊다.

### 번호 규칙 (`Worlds` in `lib/world/world_catalog.dart`)

| | 세계 1 | 세계 2 | 세계 3 | 세계 4 | 세계 5 | 세계 6 | 세계 7 | 세계 n |
|---|---|---|---|---|---|---|---|---|
| 스테이지 id | 1–25 | 101–125 | 201–225 | 301–325 | 401–425 | 501–525 | 601–625 | `(n-1)*100 + 1` 부터 |
| 전역 장 번호 | 1–5 | 6–10 | 11–15 | 16–20 | 21–25 | 26–30 | 31–35 | `(n-1)*5 + 1` 부터 |
| 정령 id | `s1-01`… | `s2-01`… | `s3-01`… | `s4-01`…`s4-25` | `s5-01`…`s5-25` | `s6-01`…`s6-25` | `s7-01`…`s7-25` | `sN-NN` |
| 열리는 조건 | 처음부터 | 장 1–5 완성 | 장 6–10 완성 | 장 11–15 완성 | 장 16–20 완성 | 장 21–25 완성 | 장 26–30 완성 | 앞 세계 다섯 장 완성 |

기록은 모두 같은 저장소(`ProgressRepository`)에 레벨 id로 남고, 별자리 완성은 성장 기록의 `completedChapters`에 전역 장 번호로 남는다. 그래서 세계를 추가해도 저장 형식은 바뀌지 않는다.

## 화면에서 보이는 곳

- **홈:** 열린 확장 세계 중 아직 못 마친 세계로 가는 입구 버튼과 **빛길 지도** 버튼. 확장 세계가 열리기 전에도 빛길 지도는 보인다.
- **빛길 지도**(`lib/world/saga_map.dart`): 일곱 세계를 한 줄로 잇는다.
  - 마친 세계: 켜진 등대와 풀린 수수께끼.
  - 진행 중: 진행 수와 "들어가기".
  - 다음 세계: 예고와 새 규칙.
  - 더 먼 세계: 이름만 보이고 부제는 `???`.
- **세계 지도**(`lib/world/world_map.dart`). 수호 판을 깨면 별자리 이름을 눌러 수호 정령의 기억과 별자리를 다시 볼 수 있다. 세계를 다 마치면 아래에 “다음 이야기” 카드가 붙는다.
- **결과 팝업**. 세계의 다섯 별자리를 모두 완성하면 열린 다음 세계의 지도로 이어진다. 다음 세계가 준비 중이면 빛길 지도에서 예고를 보여 준다.
- **거울 호수 등대**. 201번 첫 진입에서 거울 짝 안내를 세 장으로 보여 준다. 게임 방법에서 안내를 다시 열 수 있다. [한국어 화면 캡처](screenshots/world3/)
- **시계탑 등대**. 301번 첫 진입에서 바늘 방향으로 출발하기, 한 수마다 바늘 돌리기, 다른 블록으로 기다리기를 안내한다. 게임 방법에서 다시 열 수 있다. 마지막 장을 마치면 얼음 동굴 등대로 이어진다. [한국어 화면 캡처](screenshots/world4/)
- **얼음 동굴 등대**. 401번 첫 진입에서 얼음에 들어가기, 막히는 곳에 멈추기, 블록과 잔상으로 멈출 자리를 만들기를 안내한다. 게임 방법에서 다시 열 수 있다. 마지막 장을 마치면 꿈의 서고 등대로 이어진다. [한국어 화면 캡처](screenshots/world5/)
- **꿈의 서고 등대**. 501번 첫 진입에서 같은 무늬의 책장으로 건너가기, 건너편이 막히면 머무르기, 책장에서 걸어 나오기를 안내한다. 게임 방법에서 다시 열 수 있다. 마지막 장을 마치면 빛길 끝의 첫 별을 예고한다. [한국어 화면 캡처](screenshots/world6/)
- **첫 별**. 꿈의 서고를 마치면 601~625번과 전역 장 31~35가 열린다. 601번에서는 “지금까지 배운 규칙이 모두 나와요” 한 장을 보여 준다. 깊은 밤하늘 판의 테두리에는 다섯 등대 색의 별이 놓이고, 세계 1의 선율을 느리게 변주한 `bgm_w7.wav`가 흐른다. 별 75개로 ‘첫 별의 잔상’ 칭호와 ‘첫 별빛’ 이동 잔영을 얻는다. [한국어 화면 캡처](screenshots/world7/)

첫 별의 1~4장은 함께 합류한 친척들을 장별 가문 키로 묶는다. 각 정령의 생김새와 기억에는 등불·물그림자·태엽·서리·책벌레 등 원래 가문과 관계를 적었다. 625번의 `s7-25`는 아스테르와 노아·온빛·오르·서람·책별이 함께 지키는 판이다. 리크의 정체는 5장 결말에서 밝히며, 빛길 지도의 세계 수수께끼도 세계 7 완성 뒤에 보인다.

## 새 세계를 여는 순서

세계 3을 예로 든다.

1. **규칙 코드**
   - `lib/domain/mechanics/`에 기믹 파일을 하나 만든다. `board_mechanic.dart`의 훅을 구현하고 `mechanic_registry.dart`에 JSON의 `type`과 파서를 등록한다. `tools/mechanics.py`에도 같은 이름과 훅을 등록한다. 두 레지스트리의 적용 순서를 맞춘다.
   - 이동은 진입·출발 판정 → 일반 이동 또는 권능 착지 → `transformMove`로 배치 변환 → `nextEcho`로 잔상 처리 순이다. 기존 봉인과 빛 교대의 잔상 규칙은 마지막에 우선한다. 위치 외에 탐색 결과를 바꾸는 값이 있다면 `stateKey`에 넣는다.
   - 같은 `type` 키로 `lib/game/board_badge.dart`에 배지, `lib/game/bloriq_game.dart`에 보드 그리기, `lib/game/mechanic_legend.dart`에 범례를 등록한다. 문구는 `lib/l10n/app_ko.arb`와 `app_en.arb`에 넣는다.
   - Python 기믹의 `randomRule`로 검증 표본을 만들고 두 solver의 최단 수를 비교한다. 위치 목록 이외의 정보를 쓰는 기믹은 회전·대칭 중복 검사용 `auditTokens`도 구현한다. `python3 tools/validate_levels.py --write-solutions`로 공개 판과 이전 코스 보관본의 풀이 데이터를 갱신한다.

     ```bash
     python3 -m tools.power_fuzz_fixture --mechanics echoHold echoGate --count 100 --output /tmp/bloriq-fuzz.json
     flutter test test/power_solver_agreement_test.dart --dart-define=MECHANIC_FIXTURE=/tmp/bloriq-fuzz.json
     ```

2. **판 생성.** `tools/worlds/w3.py`에 슬롯 25개를 둔다. 슬롯마다 판 크기, 블록과 바위 수, 기믹, 권능, 목표 수, 탐색 예산(`quick_states`, `full_states`)과 최대 시간(`max_seconds`)을 정한다. `python3 -m tools.design_world --world 3 --workers 8`은 `assets/levels/world3.json`에 레벨 201–225와 최단 풀이를 기록한다. `--only 7`을 붙이면 일곱째 슬롯만 선택한다. 30초마다 완료된 슬롯을 저장하며 다시 실행하면 빠진 슬롯부터 이어서 만든다. 진행과 예산 초과로 버린 후보 수는 `build/design_logs/w3.log`에서 확인한다. 기존 공개 판은 `--check`로 읽기 전용 검증을 한다.
3. **이야기.** 빈 틀을 `assets/story/world3.json`으로 복사하고 `worldId`를 `"w3"`으로 설정한다. 장 5개의 `globalChapter`는 11–15이며, 장마다 0..1 좌표의 별 5개를 둔다. 정령 25명을 레벨에 연결하고 각 장 다섯째 정령을 수호자로 지정한다. 그림이 없는 정령은 `asset`을 `null`로 둔다. [이야기 틀과 필드 설명](STORY_TEMPLATE.md)
4. **사가와 테마.** `assets/worlds/saga.json`에 `levels`, `story` 경로를 적고 앞 세계부터 순서대로 `status`를 `"playable"`로 바꾼다. 선택 항목 `theme.palette`에는 `background`, `board`, `border`, `accent` 색을 `#RRGGBB`로 적는다. `floor`와 `rock`이 비어 있으면 팔레트로 판석과 바위를 그린다. 시계탑은 `woodFloor: true`로 나무결 에셋을 재사용하고 팔레트 색을 입힌다. `bgm`은 세계에 들어갈 때 재생하는 루프 경로이며, 값이 없으면 기본 곡을 쓴다. 테마가 없는 세계는 달빛 숲 스킨을 쓴다. [테마 데이터](../assets/worlds/saga.json)
5. **번들.** `pubspec.yaml`의 `assets`에 레벨·이야기 JSON과 새 그림·음원 경로를 추가한다. 이야기 빈 틀은 작업용으로 둔다.
6. **검증.** 생성기가 기믹을 하나씩 꺼 보고 최단 수가 바뀌지 않는 후보를 제외한다. 공개 전 Dart 공통 검사에서 25판, 정령·수호자 연결, 별자리와 한·영 문구, 번들 에셋, 저장 풀이를 확인하고 수동 플레이 검토를 마친다.

   ```bash
   python3 -m tools.design_world --world 3 --check
   python3 tools/validate_levels.py
   python3 -m tools.level_audit --world 3
   flutter gen-l10n
   flutter analyze
   flutter test -r failures-only
   ```

코드는 세계 번호만 받아 동작한다. 홈 입구, 지도, 권능 막대, 결과 보상, 별자리 완성 기록이 모두 새 세계에서 그대로 작동한다.

## 세계 사이를 채울 콘텐츠 (다음 후보)

세계 하나를 만드는 데는 시간이 걸린다. 그 사이에 다시 들어올 이유를 주는 후보들이다.

- **별바다 항해(끝없는 모드):** 구현됨. [ENDLESS.md](ENDLESS.md) 참고.
- **잔상의 시련:** 이미 깬 판을 이동 수 제한이나 권능 금지로 다시 낸다.
- **주간 별자리:** 일주일마다 고정 5판을 내고, 다 깨면 한정 칭호나 이동 잔영을 준다. 오늘의 잔상을 확장한 형태다.
