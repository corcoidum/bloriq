# BLORIQ 사가 — 다섯 등대의 빛길

2026-11-08 · 모든 세계를 꿰는 큰 줄거리와, 새 세계를 데이터로 붙이는 방법을 정리한 작가·개발용 문서다. 결말을 포함한다.
화면이 읽는 원본은 [`assets/worlds/saga.json`](../assets/worlds/saga.json)이다. 이 문서와 다르면 JSON이 맞다.

## 한 줄 줄거리

> 다섯 등대는 한 줄의 빛으로 이어져 첫 별까지 길을 비추고 있었다. 어느 밤 등대가 하나씩 멈추고 빛길이 끊겼다. 잔상을 남기며 걷는 리크가 등대를 하나씩 다시 켜면, 마지막에 첫 별이 기다린다.

세계 1에 이미 씨앗이 있다. 포미의 기억 "다섯 등대는 한 줄의 빛으로 이어져 있었어", 2장 결말 "다섯 등대는 하나의 길을 비추고 있었어", 5장 결말의 아스테르 고백과 리크의 별 표식. 사가는 이 씨앗을 일곱 세계로 키운다.

## 수수께끼 네 가닥

세계마다 하나씩 풀고, 세계 끝에서 다음 질문을 하나 던진다. "다음엔 뭐지?"가 다시 접속할 이유다.

| 가닥 | 처음 던지는 곳 | 풀리는 곳 |
|---|---|---|
| 리크는 누구인가 | 세계 1 · 옛 등대 기록의 별 표식 | 세계 2(등대의 첫 불씨) → 세계 7(첫 별의 마지막 잔상) |
| 잔상은 무엇인가 | 세계 2 끝 · 호수 위를 혼자 걷는 잔상 | 세계 3(잃어버린 기억이 남긴 그림자) |
| 등대는 왜 멈췄나 | 세계 1 · 아스테르의 고백 | 세계 4(멈춘 밤), 세계 5(기억 보존 장치) |
| 첫 잔상은 누가 만들었나 | 시즌 1에서 남겨 둔 질문 | 세계 6(첫 별 자신) → 세계 7 |

- 세계 7의 부제 "마지막 잔상"은 게임의 옛 제목(The Last Echo)과 이어진다.
- 새 규칙은 세계마다 하나만 더한다. 이미 배운 규칙과 권능은 다음 세계에서도 섞어 쓴다.
- 세계 3~6의 규칙은 세계를 공개할 때 Dart와 Python 기믹 레지스트리에 함께 등록한다.

## 세계 하나의 모양

모든 세계가 같은 틀을 쓴다. 그래야 데이터만 채워 넣으면 새 세계가 열린다.

- **5장 × 5스테이지 = 25판.** 각 장의 다섯째 판은 수호 정령 판이다.
- **장마다 별자리 1개.** 다섯 판을 깨면 별자리가 완성되고, 다섯 별자리를 모두 완성하면 다음 세계가 열린다.
- **정령 25명.** 판마다 한 명, 장마다 가문 하나.
- **이야기 흐름:** 세계 프롤로그 → 장 소개(intro) → 장 결말(endingTitle, ending) → 세계를 마치면 `reveal`이 풀리고 다음 세계 `teaser`가 보인다.
- **난이도 톱니:** 장의 첫 판이 가장 쉽고 다섯째 판이 정점이다. 세계 평균은 앞 세계보다 조금 깊다.

### 번호 규칙 (`Worlds` in `lib/world/world_catalog.dart`)

| | 세계 1 | 세계 2 | 세계 3 | 세계 n |
|---|---|---|---|---|
| 스테이지 id | 1–25 | 101–125 | 201–225 | `(n-1)*100 + 1` 부터 |
| 전역 장 번호 | 1–5 | 6–10 | 11–15 | `(n-1)*5 + 1` 부터 |
| 정령 id | `s1-01`… | `s2-01`… | `s3-01`… | `sN-NN` |
| 열리는 조건 | 처음부터 | 장 1–5 완성 | 장 6–10 완성 | 앞 세계 다섯 장 완성 |

기록은 모두 같은 저장소(`ProgressRepository`)에 레벨 id로 남고, 별자리 완성은 성장 기록의 `completedChapters`에 전역 장 번호로 남는다. 그래서 세계를 추가해도 저장 형식은 바뀌지 않는다.

## 화면에서 보이는 곳

- **홈:** 열린 확장 세계 중 아직 못 마친 세계로 가는 입구 버튼과 **빛길 지도** 버튼. 확장 세계가 열리기 전에도 빛길 지도는 보인다.
- **빛길 지도**(`lib/world/saga_map.dart`): 일곱 세계를 한 줄로 잇는다.
  - 마친 세계: 켜진 등대와 풀린 수수께끼.
  - 진행 중: 진행 수와 "들어가기".
  - 다음 세계: 예고와 새 규칙.
  - 더 먼 세계: 이름만 보이고 부제는 `???`.
- **세계 지도**(`lib/world/world_map.dart`): 세계를 다 마치면 아래에 "다음 이야기" 카드가 붙는다.
- **결과 팝업:** 세계의 마지막 판까지 모두 마치면 "다음" 대신 **다음 이야기** 버튼이 빛길 지도를 연다.

## 새 세계를 여는 순서

세계 3을 예로 든다.

1. **규칙 코드**
   - `lib/domain/mechanics/`에 기믹 파일을 하나 만든다. `board_mechanic.dart`의 훅을 구현하고 `mechanic_registry.dart`에 JSON의 `type`과 파서를 등록한다. `tools/mechanics.py`에도 같은 이름과 훅을 등록한다. 두 레지스트리의 적용 순서를 맞춘다.
   - 이동은 진입·출발 판정 → 일반 이동 또는 권능 착지 → `transformMove`로 배치 변환 → `nextEcho`로 잔상 처리 순이다. 기존 봉인과 빛 교대의 잔상 규칙은 마지막에 우선한다. 위치 외에 탐색 결과를 바꾸는 값이 있다면 `stateKey`에 넣는다.
   - 같은 `type` 키로 `lib/game/board_badge.dart`에 배지, `lib/game/bloriq_game.dart`에 보드 그리기, `lib/game/mechanic_legend.dart`에 범례를 등록한다. 문구는 `lib/l10n/app_ko.arb`와 `app_en.arb`에 넣는다.
   - Python 기믹의 `randomRule`로 검증 표본을 만들고 두 solver의 최단 수를 비교한다. `python3 tools/validate_levels.py --write-solutions`로 공개 판과 이전 코스 보관본의 풀이 데이터를 갱신한다.

     ```bash
     python3 -m tools.power_fuzz_fixture --mechanics echoHold echoGate --count 100 --output /tmp/bloriq-fuzz.json
     flutter test test/power_solver_agreement_test.dart --dart-define=MECHANIC_FIXTURE=/tmp/bloriq-fuzz.json
     ```

2. **판 생성:** `tools/design_world2.py`를 `tools/design_world3.py`로 복사해 `SLOTS`, 출력 경로(`assets/levels/world3.json`), id 시작(201), `world: 3`을 바꾸고 생성한다.
3. **이야기:** `assets/story/world3.json`을 `world2.json`과 같은 모양으로 쓴다. `worldId: "w3"`, 장마다 `globalChapter` 11–15, 별자리 좌표 `stars`(노드 5개, 0..1), 정령 25명.
4. **사가 등록:** `assets/worlds/saga.json`에서 세계 3의 `status`를 `"playable"`로 바꾸고 `levels`, `story` 경로를 적는다. 공개된 세계는 앞에서부터 이어져야 한다(세계 3을 건너뛰고 세계 4만 열 수 없다).
5. **번들:** `pubspec.yaml`의 `assets`에 두 JSON을 추가한다(`test/saga_test.dart`가 확인한다).
6. **검증:**
   - `python3 tools/validate_levels.py`: 사가에 공개된 모든 세계를 BFS로 다시 확인한다.
   - `python3 -m tools.level_audit --world 3`
   - `flutter analyze && flutter test`
7. **그림:** 정령 그림이 없으면 `asset: null`로 두면 된다. 화면은 별 모양 자리표시를 쓴다.

코드는 세계 번호만 받아 동작한다. 홈 입구, 지도, 권능 막대, 결과 보상, 별자리 완성 기록이 모두 새 세계에서 그대로 작동한다.

- **주간 별자리:** 일주일마다 고정 5판을 내고, 다 깨면 한정 칭호나 이동 잔영을 준다. 오늘의 잔상을 확장한 형태다.
