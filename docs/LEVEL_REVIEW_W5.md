# 세계 5 얼음 동굴 판 검토

4-A의 시곗바늘과 5-A의 얼음을 조합한 5-B 검토 기록이다. 좌표는 왼쪽 위를 (1, 1)로 세고 열, 행 순서로 적었다. 시각은 화면처럼 1/4부터 센다. [5-C 공개 화면](screenshots/world5/)

| 1. 서리 입구 | 9 → 11 → 12 → 14 → 15 | 405 |
| 2. 고드름 회랑 | 10 → 12 → 14 → 15 → 17 | 410 |

## 검증과 캡처

- 5×5의 얼음 상한은 7칸이며 실제 판은 4–5칸을 쓴다. 저장된 최단 풀이에서 얼음 때문에 착지가 연장된 수는 판마다 2–6회다. 한 수에 짝 둘이 미끄러지면 1회로 세고, 바람 자체의 이동은 제외했다.
- 세계 1–4 및 세계 5 내부의 회전·반전 중복, 유사 경고, 종류별 장식 기믹은 모두 0건이다. 최고 유사도는 413번과 412번의 0.652로 기준 0.800보다 낮다.
- Python BFS는 평균 6,318개, 최대 23,034개 상태를 발견했다. 최대는 414번이며 생성기와 Dart 검사에 적용한 상한은 20만 상태다.
- 저장 풀이를 비운 Windows Flutter 테스트 러너에서 앱의 기본 힌트 isolate를 호출했다. 25판 모두 1.5초 안에 해결했다. 평균 29.21ms, 최대 126.25ms이며 최대는 414번이다.
- 바람은 406·408번에만 있으며 각각 12→10수, 15→14수로 줄인다. 411–415번은 두 짝이 같은 수에 함께 미끄러지는 구간이 있고, 416–420번은 미끄러짐 끝에 시곗바늘에 멈춘다.
- 각 장 첫 판과 수호판의 360×740 보드 캡처를 표의 ID에 연결했다. 실기기에서 도움 없이 풀 때의 조작감과 체감 난이도는 검토 대기다.
- 감사에서 `search_space_jump` 4건을 표시했다. 경고는 자동 난이도 지표이며 중복·장식 검사를 통과했다.

생성기는 얼음 두 줄을 먼저 놓은 뒤 목표 수에 맞게 주변을 바꾼다. 시간 한도에 닿은 슬롯은 다른 시드와 검증된 같은 장의 배치에서 재탐색했다. 진행 로그는 `build/design_logs/w5.log`에 남겼다.

```sh
python3 -m tools.design_world --world 5
python3 -m tools.design_world --world 5 --check
python3 tools/validate_levels.py --write-solutions
python3 tools/validate_levels.py
python3 -m tools.level_audit --world 5
flutter test -r failures-only test/world5_levels_test.dart --dart-define=CAPTURE_WORLD5_LEVELS=true
flutter test -r failures-only test/world5_levels_test.dart --dart-define=BENCH_WORLD5_LEVELS=true
```
