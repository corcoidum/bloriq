# BLORIQ — 제품 방향과 개발 기준

## 목표

BLORIQ은 한 손으로 조작하고 짧게 재도전할 수 있는 오프라인 Android 퍼즐이다. 한국어·영어를 지원하며, 한 명의 개발자가 JSON으로 스테이지를 추가하고 solver로 검증할 수 있도록 유지한다. 최초 출시 목표인 60개 스테이지와 광고 수익화는 핵심 퍼즐의 재미와 실기기 사용성을 확인한 뒤 단계적으로 진행한다.

## 핵심 게임 방식 결정

첨부된 Commercial Android Puzzle Game 마스터 프롬프트의 디자인·품질·출시 목표는 유지한다. 문서에는 블록 이동 후 경로를 직접 그리는 방식이 제안되어 있다. 이 프로젝트에서는 사용자의 이전 플레이 피드백과 게임 방식에 대한 개발자 재량 요청을 반영해 **목표 블록을 직접 이동시키는 잔상 퍼즐**을 선택한다. 첫 조작을 쉽게 이해하도록 유지하면서 이동 순서와 잔상 스위치로 판단을 요구하기 위해서다. 이 결정은 제품 가설이며 사용자 테스트가 필요하다.

- 초록색 목표 블록을 별 출구로 이동한다. 한 번 드래그하면 한 블록이 한 칸 이동한다.
- 유효한 이동이 남긴 출발 칸의 잔상은 다음 이동을 판정하는 동안 장애물이다. 다음 유효 이동이 끝나면 이전 잔상은 새 잔상으로 교체된다.
- 스위치 위 잔상이 문을 연다. 문이 닫히는 순간 문 위에 있던 블록은 밀려나지 않고 나갈 수 있다.
- 실패한 이동은 턴을 소모하지 않는다. Undo는 블록과 잔상을 함께 복원한다. Restart는 현재 스테이지를 초기화한다.
- 스테이지마다 JSON으로 목표·블록·장애물·선택적 스위치와 문의 배치를 정의하고, 순수 Dart BFS와 별도 Python 탐색으로 최단 해를 확인한다.

## 개발 단계

1. **플레이 가능한 핵심 게임:** 조작·충돌·클리어·Undo·Restart와 검증된 스테이지. 웹은 개발 테스트용이며 Android 프로젝트를 유지한다.
2. **재방문 MVP:** 사용자 관찰 후 기기 내 진행 저장, 설정, 힌트 및 별 평가를 설계·구현하고 앱 재실행과 손상 복구를 검증한다.
3. **광고 실험:** 게임과 분리된 테스트용 광고 구현 및 동의 흐름을 Android 실기기에서 검증한다. 계정 연결·실 광고는 사용자 승인과 정책 확인 후 진행한다.
4. **베타 및 출시 준비:** 품질을 검증하면서 40개와 60개로 확대하고, 실제 기기·사용자 테스트, 출시 서명, 개인정보처리방침과 Google Play의 최신 요건을 확인한다. 공개 배포는 사용자 승인 후 진행한다.

## 검증 경계

자동 solver 통과는 해결 가능성과 계산된 최소 이동의 증거다. 퍼즐의 재미, 사용자 규칙 이해 시간, 실기기 터치·성능·효과음, 광고 동의·수익, Google Play 출시 가능성을 증명하지 않는다. 실제 검사한 플랫폼과 테스트 결과를 별도로 기록한다. 계정·서버·광고·진행 저장은 현재 구현하지 않았다. 기존 Android release 설정의 debug 서명은 스토어 제출용이 아니다.
